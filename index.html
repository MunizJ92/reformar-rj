Verificando…

Cole um token do GitHub com permissão de escrita só neste repositório. Ele fica guardado apenas neste aparelho e nunca vai para o site.

Como criar o token
  1. No GitHub, abra Settings, depois Developer settings, depois Personal access tokens, depois Fine-grained tokens.
  2. Toque em Generate new token e dê um nome, por exemplo "Painel da obra".
  3. Em Repository access, escolha Only select repositories e marque este repositório.
  4. Em Permissions, abra Repository permissions e deixe Contents como Read and write.
  5. Gere o token, copie e cole aqui.
